# 🏏 Cricket Game

A simple and interactive **Cricket Game** built with HTML, CSS, and JavaScript.

## 🌐 Live Demo

👉 [Play Cricket Game](https://mg2658094-hub.github.io/Cricket-Game/)

## 📖 About

This project is a browser-based cricket game where you play against the computer.

The game uses **JavaScript** for the game logic and **Local Storage** to save the score even after refreshing the page.

## ✨ Features

- 🏏 Play against the computer
- 🏆 Track Win, Loss, and Tie
- 💾 Save score using Local Storage
- 🔄 Reset score
- 📱 Responsive design
- 🎨 Simple and clean UI

## 🎮 How to Play

1. Open the [Live Demo](https://mg2658094-hub.github.io/Cricket-Game/).
2. Choose **Bat**, **Ball**, or **Stump**.
3. The computer will make its choice.
4. The game will calculate the result.
5. Your score will be updated automatically.
6. Your score is saved even after refreshing the page.
7. Use **Reset Score** to start again.

## 🛠️ Technologies

- **HTML5** – Structure
- **CSS3** – Styling and responsive design
- **JavaScript** – Game logic
- **Local Storage** – Score persistence
